# COFOLDER v1.0 Requirements Checklist

This checklist covers the manuscript's software requirements, the additional v1.0 interface requirements, packaging, and documentation. It deliberately excludes reproduction of the MAPK14-specific manuscript results; small test fixtures may still verify that the underlying analytical functionality works correctly.

**Basis:** M = manuscript; SI = Supporting Information; V1 = additional v1.0 contract.  
**Lane:** U = unit/contract test; A = integration or acceptance test; D = documentation verification.
