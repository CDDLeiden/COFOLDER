# Legacy

This folder contains archived material preserved for traceability during the transition to the current COFOLDER layout.

Treat these files as historical reference, not as the supported starting point for new users.

## What Lives Here

- old environment specifications
- older YAML examples
- earlier shell wrappers

## When To Use It

Use `legacy/` only when you are:

- reproducing an older workflow
- checking how a previous setup was run
- porting an older configuration into the current CLI

## When Not To Use It

If you are starting fresh, use:

- the root `README.md`
- `docs/`
- `examples/`
- `tutorials/`

Those paths reflect the current public workflow.
